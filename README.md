# 使用指南：

ESP-IDF的版本为6.0

ESP32型号：ESP32S3 Flash:4MB 无PSRAM

内存卡数据的config文件夹中的`config.txt`文件`hostName`对应我们的域名前缀，修改这里即可修改后台网址。

~~~
autoWifinum=1
wifiConnectTime=500
hostName=esp32
FirstWebis=1
~~~
